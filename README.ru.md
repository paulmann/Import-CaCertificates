## 1. Обзор

**Import-CaCertificates** — профессиональная утилита для PowerShell, которая автоматизирует загрузку и импорт корневых и промежуточных сертификатов CA в хранилище сертификатов Windows. Это особенно полезно для серверов за межсетевыми экранами, при автоматизированном развёртывании и при исправлении ошибок «Unknown CA» в почтовых серверах, таких как hMailServer и Exim.

### Назначение
Скрипт обеспечивает доверие вашей среды Windows к нужным удостоверяющим центрам (CA) так:
- Безопасная загрузка сертификатов по прямым URL.
- Импорт корневых CA в хранилище `Trusted Root Certification Authorities`.
- Импорт промежуточных CA в хранилище `Intermediate Certification Authorities`.
- Аккуратный автоматизированный способ поддерживать цепочки доверия в актуальном состоянии.

***

## 2. Ключевые возможности

- ✨ **Автоматический импорт** — обрабатывает и корневые, и промежуточные сертификаты за один проход.
- 🔍 **Проверка** — проверяет целостность сертификата перед импортом.
- 🛠️ **Безопасность при работе с правами** — включает проверку повышения прав, чтобы убедиться в наличии нужных разрешений.
- 🔄 **Принудительное обновление** — возможность повторно импортировать уже существующие сертификаты.
- 📂 **Автоочистка** — автоматически удаляет временные файлы, если не указано иное.
- 📝 **Подробное протоколирование** — пошаговые сообщения о ходе импорта в консоли.

***

## 3. Системные требования

- **Операционная система**: Windows 7, Windows Server 2012 R2 или новее.
- **PowerShell**: версия 7.5 или выше (поддерживается PowerShell Core 7.x).
- **Разрешения**: права локального администратора (нужны для изменения системных хранилищ сертификатов).
- **Сеть**: доступ в интернет для загрузки сертификатов с исходных URL.

## 4. Быстрый старт

### Шаг 1: скачать скрипт
```powershell
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/paulmann/Import-CaCertificates/main/Import-CaCertificates.ps1" -OutFile "Import-CaCertificates.ps1"
```

### Шаг 2: запуск от имени администратора
Откройте PowerShell от имени администратора и выполните:
```powershell
.\Import-CaCertificates.ps1 -RootUrl "https://example.com/root.crt" -IntermediateUrl "https://example.com/intermediate.crt"
```

***

## 5. Установка и настройка

1. Склонируйте или скачайте этот репозиторий.
2. Убедитесь, что для вашего сеанса задано `Set-ExecutionPolicy RemoteSigned`.
3. Положите скрипт в свой каталог инструментов (например, `C:\Scripts\`).

***

## 6. Как это работает

Скрипт выполняется по безопасной схеме:
1. **Проверка прав**: убеждается, что скрипт запущен с правами администратора.
2. **Подготовка среды**: создаёт временный каталог для работы с сертификатами.
3. **Этап загрузки**: получает сертификаты с помощью `Invoke-WebRequest`.
4. **Этап импорта**: 
   - Корневые сертификаты -> `LocalMachine\Root`
   - Промежуточные сертификаты -> `LocalMachine\CA`
5. **Очистка**: удаляет временные файлы и объекты.

## 7. Руководство по интеграции с Let's Encrypt

Сертификаты Let's Encrypt часто требуют, чтобы конкретные корневые и промежуточные CA были доверенными для служб Windows (например, hMailServer или Exim).

### 7.1 Типовые команды (Let's Encrypt ISRG Root X1)
Чтобы сделать доверенной стандартную цепочку Let's Encrypt:
```powershell
.\Import-CaCertificates.ps1 `
    -RootUrl "https://letsencrypt.org/certs/isrgrootx1.pem" `
    -IntermediateUrl "https://letsencrypt.org/certs/lets-encrypt-r3.pem"
```

### 7.2 Расширенные / дополнительные команды (кросс-подписанные цепочки)
Для сред, которым нужна более старая кросс-подпись DST Root CA X3 (для совместимости с устаревшими системами):
```powershell
.\Import-CaCertificates.ps1 `
    -RootUrl "https://letsencrypt.org/certs/isrg-root-x2.pem" `
    -IntermediateUrl "https://letsencrypt.org/certs/lets-encrypt-e1.pem" `
    -Force
```

## 8. Примеры использования

### Импорт только корневого CA
```powershell
.\Import-CaCertificates.ps1 -RootUrl "http://cacerts.digicert.com/DigiCertGlobalRootG2.crt"
```

### Импорт с сохранением временных файлов (для отладки)
```powershell
.\Import-CaCertificates.ps1 -RootUrl "..." -KeepFiles
```

***

## 9. Справочник параметров

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `RootUrl` | String | **Да** | URL файла сертификата корневого CA (.crt, .cer, .pem). |
| `IntermediateUrl` | String | Нет | URL файла сертификата промежуточного CA. |
| `Force` | Switch | Нет | Принудительно повторно импортировать сертификаты, даже если они уже есть. |
| `KeepFiles` | Switch | Нет | Не удалять временные файлы по завершении. |

***

## 10. Решение проблем

- **Ошибка «Script must be run elevated»** — щёлкните PowerShell правой кнопкой мыши и выберите «Запуск от имени администратора».
- **Unknown CA в hMailServer** — после запуска скрипта перезапустите службу hMailServer, чтобы она подхватила новые доверенные CA.
- **Сбой загрузки** — убедитесь, что межсетевой экран разрешает исходящие HTTPS-запросы к поставщику сертификатов.
