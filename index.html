Import-CaCertificates

Pinned fingerprints, safe CA import

PowerShell 7.4+ module and CLI that imports Root and Intermediate CA certificates into Windows certificate stores. Every imported certificate must match an expected SHA-256 fingerprint; plain HTTP, PFX/P12 files and private keys are refused.

What it does

  • Pins SHA-256 fingerprints; a Root CA is refused without one
  • HTTPS-only downloads; no private keys, no PFX/P12
  • Validates validity period, CA role, Key Usage and signature algorithm
  • Chain-checks root/intermediate pairs before import
  • Idempotent by SHA-256; -WhatIf, -Json, -PassThru and exit codes
  • LocalMachine and CurrentUser stores; PEM, DER, multi-certificate PEM and directories

Install

  • Download the release archive and SHA256SUMS
  • Quick start with a pinned fingerprint
  • Security model and limits

Requirements

PowerShell 7.4+ · Windows 10 1607+ / Windows 11 / Windows Server 2012 R2+ · administrator for LocalMachine stores
